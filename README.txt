# Wedding Invitation Prototype

Open `index.html` in a browser to preview the mobile-first invitation.

Replace the placeholders in `index.html`:
- Bride / Groom names
- Wedding time and venue
- Reception time and venue
- Google Maps link
- RSVP / WhatsApp link

The supplied pre-wedding video and four supplied photos are already included in `assets/`.

For a public invitation link, upload this folder to a static host such as GitHub Pages, Netlify, or Vercel.
